# research/kaggle-gemma4: graph-anchored experience memory for small coding agents

This folder holds Renor's entry to two Kaggle competitions, in one place:
- the **Gemma 4 Developer Agent Paper Track** (Writeup due 12 Nov 2026, 23:59 UTC);
- the main **Gemma 4 Developer Agent Competition** (due 2 Dec 2026).

**Claim under test:** memory anchored to the code graph helps small coding agents.

**Status:** design, harness-independent code, statistics and paper skeleton only. **No model has
been run and there are no results.** The Kaggle dataset (HARNESS_README.md) needs the owner's
login and was not readable when this was written, so every harness-specific line sits behind a
marked **ADAPTER**.

| Path | What it is |
| --- | --- |
| `DESIGN.md` | Hypothesis, preregistered metric and decision rule, arms, splits, lesson schema, retrieval, budget, threats to validity. **Read first.** |
| `RELATED.md` | Prior work. Each arXiv ID was opened and checked, and the file states plainly what is new. |
| `memory/` | Lesson schema, a store keyed by node id, the three arms (`none`, `flat`, `graph`), self-distillation from attempt logs, and the ADAPTER interface (`memory/adapter.py`). Standard library only. |
| `agent/` | ADK agent config skeleton (`agent.yaml`), prompts, and the `graph_memory` skill with the `recall_lessons` tool and the lesson-injection callback. |
| `runner/` | The experiment protocol (baseline → distil → leave-one-repo-out), the budget planner, the pre-run probes, and the `submission.zip` builder. |
| `stats/` | Paired bootstrap CI (task-clustered), exact sign test, Holm correction, cost table, and the preregistered analysis. |
| `fake_harness/` | A deterministic offline stand-in for the harness, used only to test the mechanics. Nothing it measures is a result. |
| `notebook/` | The Kaggle notebook (`gemma4_graph_memory.ipynb`, generated by `make_notebook.py`). It reproduces every number offline. |
| `paper/` | Kaggle Writeup skeleton (`WRITEUP.md`, at most 3,000 words, tables left TODO) and an arXiv-style LaTeX skeleton (`arxiv/`). |

## Tests

No dependencies are needed beyond Python 3.10 or later:

```bash
cd research/kaggle-gemma4
python3 -m unittest discover -s tests -t . -v
```

The tests check:
- **Arms:** each of the three behaves as specified, deterministically.
- **Distillation:** it rejects invented anchors, gold strings and non-Gemma authors.
- **Pipeline:** the leave-one-repo-out pipeline never puts a held-out repo's lessons in its own fold.
- **Statistics:** they match exact values.
- **Submission zip:** it imports from its own root.
- **Notebook:** it runs end to end, offline, on the fake harness.
- **Writeup:** it stays under 3,000 words, and its results tables are all TODO.
